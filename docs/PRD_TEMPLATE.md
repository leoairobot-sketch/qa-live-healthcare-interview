## 8. 验收标准（可测试）

[每条 = 一条 Requirement（ SHALL 语句）+ 若干 Scenario（WHEN/THEN）。此章直接对应 API_TEST.md 的测试用例，逐条可翻译为 curl 或前端断言。]

### 8.1 登录鉴权

#### Requirement: 系统应当校验用户名密码并返回 Token
系统**应当(SHALL)**对已注册用户提供用户名密码登录，成功返回 Token，失败返回 401。

- **Scenario: 正确的用户名和密码**
  - **WHEN** 用户以正确用户名和密码调用 POST /api/auth/login
  - **THEN** 返回 200 及有效 Token
- **Scenario: 密码错误**
  - **WHEN** 用户以错误密码调用登录接口
  - **THEN** 返回 401，提示"用户名或密码错误"，且不区分是用户名还是密码错误
